\# OIBSIP - Oasis Infobyte Data Science Internship



This repository contains my complete \*\*Oasis Infobyte Data Science Internship (OIBSIP)\*\* work, including all five Data Science tasks.



All five tasks are organized independently with their own notebooks, datasets where applicable, and task-specific README files.



\---



\## Tasks Completed



\### Task 1 - Iris Flower Classification



\*\*Objective:\*\* Classify Iris flowers into their respective species using machine learning.



\*\*Key work:\*\*

\- Exploratory Data Analysis

\- Feature analysis and visualization

\- Pairplot and boxplots

\- Train/test split

\- Logistic Regression

\- K-Nearest Neighbors

\- Random Forest

\- Accuracy, precision, recall and F1-score

\- Confusion matrices

\- Model comparison and selection



\*\*Notebook:\*\* `Task1\_Iris\_Flower\_Classification/Iris\_Flower\_Classification.ipynb`

\*\*Key work:\*\*

\### Task 3 - Car Price Prediction



\*\*Objective:\*\* Predict used-car selling prices using machine learning regression models.



\*\*Key work:\*\*

\- Data cleaning

\- Duplicate and missing-value handling

\- Car age feature engineering

\- Brand extraction

\- Exploratory Data Analysis

\- Categorical encoding

\- Correlation analysis

\- Linear Regression

\- Random Forest Regression

\- Gradient Boosting Regression

\- MAE, RMSE and R2 evaluation

\- Best-model selection

\- Coefficient-based feature importance



\*\*Best model:\*\* Linear Regression



\*\*Test R2:\*\* 0.7786



\*\*Notebook:\*\* `Task3\_Car\_Price\_Prediction/Car\_Price\_Prediction.ipynb`

\### Task 4 - Email Spam Detection



\*\*Objective:\*\* Classify SMS messages as ham or spam using Natural Language Processing and machine learning.



\*\*Key work:\*\*

\- Class distribution analysis

\- Text preprocessing

\- TF-IDF vectorization

\- Multinomial Naive Bayes

\- Logistic Regression

\- Accuracy, precision, recall and F1-score

\- Classification reports

\- Confusion matrices

\- Spam recall analysis

\- WordCloud visualization



\*\*Best model:\*\* Multinomial Naive Bayes



\*\*Accuracy:\*\* 97.04%



\*\*Spam Precision:\*\* 100.00%



\*\*Spam Recall:\*\* 77.85%



\*\*Spam F1-score:\*\* 87.55%



\*\*Notebook:\*\* `Task4\_Email\_Spam\_Detection/Email\_Spam\_Detection.ipynb`
